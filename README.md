# Projects

Everything [EnderNoch](https://github.com/EnderNoch) (Atypical Maker) makes, in one place. Collections group related projects; each project lives in its own repository.

*[Po polsku niżej.](#po-polsku)*

## Collections

| Collection | What's in it |
| --- | --- |
| **[Atypical Maker Mac Apps](https://github.com/EnderNoch/Atypical-Maker-Mac-Apps)** | Small Mac apps that each do one thing and look like part of macOS 26/27: [Screen Light](https://github.com/EnderNoch/Screen-Light), [Timer](https://github.com/EnderNoch/Timer), [Flashcards from File](https://github.com/EnderNoch/Flashcards-from-File) |
| **[Minecraft Projects](https://github.com/EnderNoch/Minecraft-Projects)** | Minecraft mods and resource packs for Java Edition 26.3: [Centered Loading Bar](https://github.com/EnderNoch/Centered-Loading-Bar), [Monocraft Font](https://github.com/EnderNoch/Monocraft-Font) |

## Other projects

| Project | What it does |
| --- | --- |
| **[Steam Windows on Mac](https://github.com/EnderNoch/Steam-Windows-on-Mac)** | Steam for Windows on an Apple silicon Mac, for free: Sikarugir wrapper setup, script and icon |
| **[Spotlight at Cursor](https://github.com/EnderNoch/spotlight-at-cursor)** | The built-in macOS Spotlight opens at the mouse cursor instead of its remembered spot, with no background process |
| **[rickthatrolls](https://github.com/EnderNoch/rickthatrolls)** | A web page that plays a video on a loop with nothing on the page to stop it. [Open it](https://endernoch.github.io/rickthatrolls/) |
| **[fiszki-z-pliku](https://github.com/EnderNoch/fiszki-z-pliku)** | Turns flashcards from a file into an HTML page (the web predecessor of Flashcards from File). [Open it](https://endernoch.github.io/fiszki-z-pliku/) |
| **[endernoch.github.io](https://github.com/EnderNoch/endernoch.github.io)** | The site at [endernoch.github.io](https://endernoch.github.io/) |

## Po polsku

Wszystko, co robi EnderNoch (Atypical Maker), w jednym miejscu. Kolekcje zbierają powiązane projekty, a każdy projekt ma własne repozytorium.

**Kolekcje**

- **[Atypical Maker Mac Apps](https://github.com/EnderNoch/Atypical-Maker-Mac-Apps)** — małe aplikacje na Maca, każda robi jedną rzecz i wygląda jak część macOS 26/27: [Światło ekranu](https://github.com/EnderNoch/Screen-Light), [Minutnik](https://github.com/EnderNoch/Timer), [Fiszki z pliku](https://github.com/EnderNoch/Flashcards-from-File)
- **[Minecraft Projects](https://github.com/EnderNoch/Minecraft-Projects)** — mody i paczki zasobów do Minecraft Java Edition 26.3: [Centered Loading Bar](https://github.com/EnderNoch/Centered-Loading-Bar), [Monocraft Font](https://github.com/EnderNoch/Monocraft-Font)

**Inne projekty**

- **[Steam Windows on Mac](https://github.com/EnderNoch/Steam-Windows-on-Mac)** — Steam w wersji na Windowsa na Macu z procesorem Apple, za darmo: konfiguracja Sikarugir, skrypt i ikona
- **[Spotlight pod kursorem](https://github.com/EnderNoch/spotlight-at-cursor)** — wbudowany Spotlight otwiera się tam, gdzie stoi kursor, bez procesu w tle
- **[rickthatrolls](https://github.com/EnderNoch/rickthatrolls)** — strona, która odtwarza film w pętli i nie ma niczego, czym dałoby się go zatrzymać. [Otwórz](https://endernoch.github.io/rickthatrolls/)
- **[fiszki-z-pliku](https://github.com/EnderNoch/fiszki-z-pliku)** — zamienia fiszki z pliku na stronę HTML (internetowy poprzednik Fiszek z pliku). [Otwórz](https://endernoch.github.io/fiszki-z-pliku/)
- **[endernoch.github.io](https://github.com/EnderNoch/endernoch.github.io)** — strona [endernoch.github.io](https://endernoch.github.io/)
